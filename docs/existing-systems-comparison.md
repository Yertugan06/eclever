# Comparison of existing programming-learning systems

**Method (22 October 2026).** We selected five systems from a 14-product longlist: two Russian/Central Asian school platforms, two Python game/course platforms for the target age, and one prominent AI tutor with Python coursework. The longlist also considered Codecademy (terms require 16+), Code.org (its Python Lab is 13+ and English), Stepik (course marketplace), Tynker, Mimo, Sololearn, Yandex Lyceum, Daryn.Online and Algoritmika. Selection reflects relevance and the availability of first-party documentation, not a ranking of educational quality. The matrix uses only vendor pages, vendor help pages or source repositories linked below. A missing public description is **ND (not documented)**, not evidence that a feature does not exist.

## Criteria and rating

`Y` = explicitly supported; `P` = partial or context-limited; `N` = documented limitation or exclusion; `ND` = no reliable documentation found. Each criterion is applied to the same target: a Kazakhstan Student in grades 6–8 practising **typed Python**.

| Code | Criterion and assessment rule |
|---|---|
| C1 | Age fit: product/course is designed and permitted for ages about 11–14. |
| C2 | Typed Python: a Student writes actual Python, not only blocks. |
| C3 | Automatic code checking: code is run/checked and feedback returned. |
| C4 | Knowledge-model adaptivity: a per-Skill estimate selects the next Python Exercise; a placement test or fixed path does not suffice. |
| C5 | AI help without current solution: a Student-facing AI helper with an explicit answer-withholding claim; graduated levels count only if documented. |
| C6 | Per-Skill Teacher view: a Teacher can inspect a Student's difficulty by programming Skill, beyond completion or marks. |
| C7 | Russian and Kazakh: `Y` both, `P` one or incomplete, `N` neither. Course-language gaps are noted. |
| C8 | Kazakhstan curriculum: explicit mapping to Order 399 objectives. |
| C9 | Kazakhstan access: documented availability and age-appropriate route; cost shown where verified. |

## Interpretation and limits

Yandex Uchebnik already documents browser Python tasks with automatic code checking and a Teacher topic view; it is a strong Russian-language benchmark. Its public pages do not establish a per-Skill knowledge model that chooses the next Python task or graduated code hints. Bilimland is locally relevant and bilingual, with Teacher progress monitoring, while typed-Python execution and mastery-driven adaptation are not established by the pages reviewed. CodeMonkey fits the age range and has graded Python courses, but its published course material does not describe an LLM hint ladder. CodeCombat explicitly claims AI hints without direct answers and offers classroom controls; a four-level design and per-Skill mastery view were not documented. Khanmigo makes a similar tutoring claim and Khan Academy offers auto-checked Python, but its learner subscription requires a US residence and billing address.

The proposed gap is the **combination** of curriculum-mapped typed Python, mastery-driven selection, graduated checked Hints and a per-Skill Teacher view for a Kazakhstan classroom. The table does not prove superiority. EClever must still implement and evaluate these features. Commercial capabilities, localisation and terms can change; this comparison is a dated snapshot.
